# دليل كتابة المحتوى

كيف تُكتب ملفات المحتوى، وأين توضع، وما الذي يفحصه البناء. المرجع الأعلى لكل ما هنا هو [وثيقة الأساس](foundation.md).

## أين يوضع كل شيء؟

```text
src/content/
  parts/       الأبواب: ملف لكل باب (0.yaml … 8.yaml)، وفيه خطة محطاته
  stations/    المحطات: ملف MDX لكل محطة، اسمه رقمها بشرطة (1-2.mdx للمحطة 1.2)
  people/      الأعلام: ملف Markdown لكل علَم
  texts/       النصوص: ملف Markdown لكل نص (القصيدة، الخطبة، المقامة…)
  verses/      الأبيات: مجلد لكل نص باسم معرّفه، وفيه ملف لكل بيت (001.yaml، 002.yaml…)
  stories/     الحكايات والأخبار
  concepts/    المفاهيم والمصطلحات
  sources/     الكتب: ملف لكل كتاب بطبعته، مرة واحدة فقط
```

اسم الملف هو معرّف الكيان ورابطه: `people/imru-al-qais.md` يصبح `/people/imru-al-qais/`، ويُشار إليه في الملفات الأخرى بـ `imru-al-qais`. المعرّفات بحروف لاتينية صغيرة وشرطات.

## الإحالة إلى المصادر

الكتاب يُسجَّل مرة واحدة في `sources/`، والموضع (الجزء والصفحة) يُكتب عند الإحالة.

**قائمة المصادر في الكيان** (بيت، نص، علَم، محطة…):

```yaml
sources:
  - source: zawzani
    loc: ص 12
    url: https://…            # اختياري: رابط الموضع في النسخة الرقمية
    note: شرح المطلع.         # اختياري: ما الذي أُخذ من هذا الموضع
```

**الإحالة داخل نص في ملف YAML** (معنى البيت، البلاغة، الروايات…):

```yaml
meaning: … كما يشرحه الزوزني [@zawzani، ص 12].
```

**الإحالة داخل محطة (MDX):**

```mdx
وقف الشاعر على الديار يبكيها <Cite id="zawzani" loc="ص 12" />.
```

**القاعدة:** ما عليه إحالة فهو نقل عن المصدر، وما لا إحالة عليه فهو قراءة للنص. لذلك لا تُكتب معلومة تاريخية بلا إحالة.

## التشكيل

القارئ لا يعرف نطق الأعلام، فلا نتركه يخمّن.

- **يُشكَّل في كل موضع:** أسماء الأشخاص والقبائل والمواضع والأيام والكتب (ابن رَشِيق، دُرَيْد بن الصِّمَّة، غَزِيَّة، عُكاظ، العُمْدة)، والمصطلح الذي قد يُقرأ على غير وجهه (الرَّوِيّ، العَرُوض، العَجُز، الإِقْواء)، والكلمة الغريبة.
- **يُشكَّل تشكيلًا تامًّا:** البيت، وكل شطر أو عبارة من شعر تُقتبس داخل النثر، وكل رواية في `variants`، وكل كلمة في `vocabulary` كما وردت في البيت.
- **لا يُشكَّل:** ما لا لبس فيه من الكلام العادي؛ فكثرة الحركات تُثقل القراءة.
- البحث يجد الكلمة المشكولة وإن كُتبت بلا تشكيل، فلا خوف على البحث من التشكيل.

## البعد عن عصرنا

كل تاريخ يُذكر يُقرن ببعده عن زمن القارئ: «سنة 41هـ (قبل نحو 1370 سنة)». لا يُكتب الرقم بيد، بل يحسبه البناء من سنة البناء نفسها، فيبقى صحيحًا مع الزمن.

- **في نص YAML أو Markdown:** `[~630]` لسنة ميلادية، و`[~h41]` لسنة هجرية، فيظهر مكانها «قبل نحو 1400 سنة». وتُكتب الأقواس والفواصل حولها باليد: `سنة 41هـ ([~661])`.
- **في المحطة (MDX):** `<Ago g={661} />` أو `<Ago h={41} />`.
- **تلقائيًا بلا علامة:** تاريخ الوفاة المكتوب هكذا «(ت 463هـ)» أو «(ت 1332هـ / 1914م)» يُضاف إليه البعد في النصوص وقائمة المصادر. وتواريخ الأعلام في `born` و`died` يُعرض بعدها في البطاقة وصفحة العلَم. وإذا كان التاريخ تقريبيًا بصيغة حرة (`text`) فأضف إليه `g` بسنة تقريبية ليُحسب منها البعد.
- **الأبواب:** الحقل `start` في ملف الباب سنة بدايته الميلادية التقريبية، ويظهر بعدها في خريطة الرحلة.
- يكفي أن يُقرن التاريخ ببعده في أول ذكر له في الصفحة.

## تنبيهات YAML

- إذا بدأ النص بـ `[` أو احتوى على نقطتين تليهما مسافة (`: `)، ضعه بين علامتي تنصيص مزدوجتين:
  `- "والتقدير: …"`
- الأرقام التي تشبه الأعداد العشرية (مثل رقم المحطة `1.2`) توضع بين علامتي تنصيص: `number: '1.2'`.

## البيت

```yaml
first: قِفا نَبكِ مِن ذِكرى حَبيبٍ وَمَنزِلِ     # الصدر، مشكولًا كاملًا
second: بِسِقطِ اللِوى بَينَ الدَخولِ فَحَومَلِ     # العجز
level: basic            # basic: المعنى والمفردات فقط. full: التحليل الكامل
meaning: …
vocabulary:
  - term: …
    text: …
context: …              # وظيفة البيت في القصيدة
# الحقول التالية إلزامية حين يكون level: full
syntax: [ … ]
morphology: [ … ]
rhetoric:
  thesis: …
  devices:
    - title: …
      text: …
  connection: …         # صلة البيت بما بعده (اختياري)
prosody:
  meter: البحر الطويل
  rhyme: …
  scansion: …           # التقطيع (اختياري)
  note: …
variants:               # الروايات (اختياري)
  - reading: …
    status: …
    note: …
sources: [ … ]
status: draft
```

## المحطة

ترويسة المحطة تحمل بياناتها، ومتنها نص MDX مقسوم بعناوين `##`: المدخل، والسياق، والأعلام، والقراءة، وأداة جديدة، وحكايات وأخبار. أما الحصيلة وأبيات الحفظ وأسئلة المراجعة والمصادر فتُكتب في الترويسة، ويعرضها القالب في آخر المحطة.

```yaml
part: '1'
number: '1.2'
title: …
subtitle: …
minutes: 20
people: [imru-al-qais]
texts: [qifa-nabki]
concepts: [tawil]
stories: []
outcomes: [ … ]
review:
  - q: …
    a: …
memorize: [qifa-nabki/001]
sources: [ … ]
status: draft
```

**المكوّنات المتاحة داخل المحطة:**

| المكوّن | وظيفته |
|---|---|
| `<Reading text="…" from={1} to={12} />` | قارئ الأبيات لنص أو لمقطع منه |
| `<VerseQuote id="نص/001" />` | اقتباس بيت واحد مع نسبته |
| `<Cite id="…" loc="…" />` | إحالة داخل الجملة |
| `<PersonCard id="…" />` | بطاقة علَم |
| `<ConceptCard id="…" />` | بطاقة مفهوم |
| `<StoryCard id="…" />` | بطاقة حكاية مع درجتها |

## الحكاية

```yaml
title: …
summary: …              # سطر واحد يلخص الخبر
grade: mashhur          # thabit | khilaf | mashhur | manhul
gradeReason: …          # لماذا هذه الدرجة
earliest:               # أقدم مصدر ذكر الخبر
  source: …
  loc: …
people: [ … ]
status: draft
```

متن الملف هو الحكاية بصياغتنا.

## الحالة

| القيمة | المعنى |
|---|---|
| `draft` | مسودة: لم تمر بعد بمنهج البحث كاملًا |
| `review` | قيد المراجعة: اكتمل بحثها وتنتظر مراجعتك |
| `approved` | معتمد: روجعت واعتُمدت |

## ما الذي يُفشل البناء؟

- مرجع إلى كيان غير موجود (علَم، نص، مفهوم، بيت، مصدر…).
- إحالة داخل النص إلى مصدر غير موجود.
- بيت تحليله كامل وينقصه النحو أو الصرف أو البلاغة أو الوزن.
- بيت في مجلد لا يقابله نص.
- محطة لا يطابق اسم ملفها رقمها، أو رقمها لا يطابق بابها.

## الأوامر

```sh
npm install        # مرة واحدة
npm run dev        # معاينة محلية أثناء الكتابة (البحث لا يعمل فيها)
npm run build      # بناء الموقع وفهرس البحث في dist/
npm run preview    # تشغيل النسخة المبنية كما ستعمل على Cloudflare
```
