# الشعر والأدب العربي

مرجع عربي تفاعلي ثابت لفهم تاريخ الأدب والنصوص، لا مجرد أرشيف قصائد.

## المعمار الحالي — V2

الموقع موسوعة واحدة بعمقين داخل الموضوع نفسه:

- **الخلاصة:** الخريطة الكبرى، موضع العصر، التحولات الأساسية، الأعلام والنصوص المفاتيح.
- **التعمق:** التاريخ الأدق، اللغة والنحو والصرف، البلاغة، الوزن والقافية، السياق، الروايات والمصادر.

لا توجد بنية «عصر ← شاعر واحد ← قصيدة واحدة». العصر بوابة تضم سياقًا أدبيًا واسعًا، والشاعر عقدة داخل شبكة من الأعلام والنصوص.

## العينة البحثية الحالية

- العصر العباسي، مع تكبير العدسة على القرن الرابع الهجري وحلب الحمدانية.
- أبو الطيب المتنبي.
- قصيدة «على قدر أهل العزم تأتي العزائم» في سياق ثغر الحدث سنة 343هـ.
- أول ثمانية أبيات محللة طبقيًا لاختبار منهج قارئ القصيدة قبل توسيع النص الكامل.

## قارئ البيت

كل بيت له معرّف ثابت، ويمكن فتح:

- المعنى
- المفردات
- النحو والتركيب
- الصرف والاشتقاق
- البلاغة
- الوزن والقافية
- السياق والروايات
- المصادر

التحليل البلاغي لا يكتفي بتسمية المحسن، بل يبحث وظيفة التقديم، والتركيب، والاشتقاق، والصورة، والحجاج، وصلات الأبيات بعضها ببعض.

## التوثيق

المصادر المستخدمة في العينة ظاهرة داخل الموقع، ومنها شرح الواحدي، وشرح البرقوقي، وشرح المشكل لابن سيده، وشرح ابن الإفليلي. لا تُعامل القراءة التحليلية للمشروع بوصفها كلامًا منقولًا عن هذه المصادر.
